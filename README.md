# Happy Birthday Amma - Sowjanya 🎂🎉

An interactive birthday celebration website created with love for Amma.

## ✨ Features
- **Interactive Wax-Seal Envelope**: Tap the golden "S" seal to open with confetti.
- **Background Music**: Celebratory audio track (`the_mountain-happy-birthday-508020.mp3`).
- **Hero Section**: Dedicated greeting to the "Birthday Queen 👑".
- **Memory Wall**: 3D tilt polaroid gallery displaying family photos with lightbox view.
- **Voice Notes from Asritha & Rigved**: Real audio greetings from both children with animated equalizers.
- **3D Interactive Birthday Cake**: Three.js multi-tier cake with rotatable view, microphone-enabled candle blowing, and relighting.
- **Mobile Responsive**: Fully optimized for phones, tablets, and desktops.

## 🚀 Running Locally
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
