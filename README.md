# Happy Birthday Sowjanya! 🎂✨

An interactive birthday celebration website created with love for Amma by Asritha & Rigved.

## Features
- 💌 Interactive 3D wax-seal envelope opener
- 👑 Hero greeting with 3D photo tilt & floating hearts
- 📸 Interactive 3D Polaroid memory wall
- 🎙️ Personalized wishes & voice notes from Asritha 👧 and Rigved 👦 (compatible with iOS Safari, Android, and desktop)
- 🎂 Interactive 3D birthday cake with blowable candles (microphone detection)
- 🎵 Background celebration music with mute/volume controls

## Running Locally
```bash
node local-server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
